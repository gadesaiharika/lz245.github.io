# 第030课 单元总结 · 藏象体系图

## ① 复习昨天

先背出昨天的五句"所合所荣"，再回答下面三个问题。

> [!question]- 复习1：五脏"所合"（五体）与"所荣"各是什么？
> 心合脉，荣于色；肺合皮，荣于毛；肝合筋，荣于爪；脾合肉，荣于唇；肾合骨，荣于发。

> [!question]- 复习2：《五藏生成》的"所合、所荣"与《六节藏象论》的"其充、其华"是什么关系？
> 一体两说：所合≈其充，所荣≈其华；《五藏生成》补齐了《六节藏象论》未列的脾（合肉、荣唇）。

> [!question]- 复习3：这张五脏外候表将为后面哪个单元埋下伏笔？
> 第七单元诊法——望面色、察口唇爪甲毛发的荣枯，由体表反推五脏盛衰，正是"司外揣内"的操作化。

## ② 本单元知识地图

藏象十课，其实是一张图：**内核（藏）→ 功能（官）→ 外候（象）**。

**第一块：十二官相使表（《灵兰秘典论》，第021～023课）**

| 脏腑 | 官名 | 职能 |
| --- | --- | --- |
| 心 | 君主之官 | 神明出焉 |
| 肺 | 相傅之官 | 治节出焉 |
| 肝 | 将军之官 | 谋虑出焉 |
| 胆 | 中正之官 | 决断出焉 |
| 膻中 | 臣使之官 | 喜乐出焉 |
| 脾胃 | 仓廪之官 | 五味出焉 |
| 大肠 | 传道之官 | 变化出焉 |
| 小肠 | 受盛之官 | 化物出焉 |
| 肾 | 作强之官 | 伎巧出焉 |
| 三焦 | 决渎之官 | 水道出焉 |
| 膀胱 | 州都之官 | 津液藏焉，气化则能出矣 |

总结论：**凡此十二官者，不得相失也。主明则下安，主不明则十二官危。**

**第二块：藏象核心（第024～029课）**

- **方法**：藏居于内，象见于外——司外揣内（第024课）。
- **分类**：五脏藏精气而不泻，满而不能实；六腑传化物而不藏，实而不能满；奇恒之腑（脑、髓、骨、脉、胆、女子胞）形似腑而用似脏（第026课）。
- **整体**：魄门亦为五脏使；胃者水谷之海，六腑之大源——后天之本的雏形（第027课）。
- **藏神**：神—心，魂—肝，魄—肺，意—脾，志—肾（第028课）。
- **外候**：五脏之本与其华其充（第025课）；所合五体与所荣（第029课）——心脉色、肺皮毛、肝筋爪、脾肉唇、肾骨发。

## ③ 重点原文回顾

本单元必背句清单，逐句背出后再打勾：

- [ ] 心者，君主之官也，神明出焉。（021）
- [ ] 肺者，相傅之官，治节出焉。肝者，将军之官，谋虑出焉。（022，连诵胆、膻中、脾胃三句）
- [ ] 凡此十二官者，不得相失也。故主明则下安，以此养生则寿。（023）
- [ ] 帝曰：藏象何如？岐伯曰：心者，生之本，神之变也。（024）
- [ ] 心者，生之本，神之变也，其华在面，其充在血脉。（025）
- [ ] 五藏者，藏精气而不泻也，故满而不能实；六府者，传化物而不藏，故实而不能满也。（026）
- [ ] 胃者，水谷之海，六府之大源也。（027）
- [ ] 肝藏血，血舍魂。脾藏营，营舍意。心藏脉，脉舍神。肺藏气，气舍魄。肾藏精，精舍志。（028）
- [ ] 心之合脉也，其荣色也。（029，连诵肺、肝、脾、肾四句）

## ④ 综合问答

本单元最容易混的几处，先自己答，再展开对照。

> [!question]- 综合1：不看表，按"心肺肝胆膻中、脾胃大肠小肠、肾三焦膀胱"的顺序，把十二官的官名全部背出来。
> 心—君主之官；肺—相傅之官；肝—将军之官；胆—中正之官；膻中—臣使之官；脾胃—仓廪之官；大肠—传道之官；小肠—受盛之官；肾—作强之官；三焦—决渎之官；膀胱—州都之官。（脾胃合任一官，故十二藏而十一官名。）

> [!question]- 综合2：最易张冠李戴的四组"出焉"——谋虑与决断、变化与化物、治节与伎巧、喜乐与神明——各归谁？
> **谋虑**归肝（将军），**决断**归胆（中正）：谋而后断。**化物**归小肠（受盛，精细消化），**变化**归大肠（传道，糟粕成形）。**治节**归肺（相傅），**伎巧**归肾（作强）。**神明**归心（君主），**喜乐**归膻中（臣使）。

> [!question]- 综合3：奇恒之腑与传化之腑的名单各是什么？哪一个成员身兼两册？
> 奇恒之腑（六）：脑、髓、骨、脉、胆、女子胞——藏而不泻；传化之腑（五）：胃、大肠、小肠、三焦、膀胱——泻而不藏。**胆**身兼两册：列六腑而藏精汁不泻，故又入奇恒之腑。

> [!question]- 综合4："满而不能实"与"实而不能满"各说谁？"满"与"实"何解？
> "满而不能实"说**五脏**（藏精气而不泻），"实而不能满"说**六腑**（传化物而不藏）。"满"指精气之盈满（无形），"实"指水谷之填塞（有形）——脏宜藏，腑宜通。

> [!question]- 综合5：五脏所藏五神，一口气对出来；并说出哪两个最易互换、如何区分。
> 神—心，魂—肝，魄—肺，意—脾，志—肾。最易互换的是**魂与魄**：魂随神往来，主想象梦寐，住在**肝血**里；魄并精出入，主本能感觉动作，住在**肺气**里。记法：肝血养"想"（魂），肺气司"动"（魄）。

> [!question]- 综合6：五脏的"所合"与"所荣"各是什么？它与"其华、其充"如何对齐？
> 心—脉—色，肺—皮—毛，肝—筋—爪，脾—肉—唇，肾—骨—发。对齐关系：所合≈其充（形体组织），所荣≈其华（外显光彩）。

## ⑤ 易混点提醒

- **十二藏≠十二个官名**：脾胃合任"仓廪之官"，故十二藏只有十一个官名——考自己时别数错。
- **膻中≠胸口的一个穴位名**：在《灵兰秘典论》语境中指心包络一系（臣使之官），代君行令、喜乐出焉。
- **胆的双重身份**：既是六腑之一（中正之官），又入奇恒之腑（藏精汁而不泻）——两份名单都要有它。
- **脉的双重身份**：脉既是心之所合（五体之一），又列于奇恒之腑名单——不矛盾，分类角度不同。
- **"化物"在小肠、"变化"在大肠**：受盛化物在前（精加工），传道变化在后（收尾）——按消化流程记就不会错。
- **"心主神明"是功能概念**：整个单元的官职、藏神、外候，讲的都是功能系统与外在征象的对应，不是解剖定位——这是读藏象的总钥匙。
